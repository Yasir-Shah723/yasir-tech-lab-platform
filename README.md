# Yasir Tech Lab

> Official personal brand, engineering portfolio, and web solutions platform of **Syed Yasir Shah** — Full Stack Developer & Web Solutions Specialist based in Rawalpindi / Islamabad, Pakistan.

## Architecture Overview
- **Frontend:** React, Vite, React Router, Tailwind CSS
- **Backend:** Node.js, Express.js, REST API
- **Database:** MongoDB (Local development with Compass / Production on MongoDB Atlas)
- **Security:** JWT authentication, role-based protection, strict input sanitization, rate limiting

## Directory Structure
- `frontend/`: Client single page application (SPA)
- `backend/`: Server application and REST endpoints
